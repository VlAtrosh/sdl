Стек технологий для 3D-рендеринга с использованием SDL
Основные технологии
1.	SDL2 (Simple DirectMedia Layer 2)
o	Основная библиотека для создания окна, рендеринга и обработки ввода
o	Используется для:
	Создания графического окна
	Рендеринга треугольников
	Обработки пользовательского ввода (клавиатура)
	Управления основным циклом приложения

3.	SDL_image
o	Дополнительная библиотека для работы с изображениями
o	Используется для:
	Загрузки текстур из файлов (PNG)
	Преобразования изображений в текстуры для рендеринга
Взаимосвязь технологий

1.	Графический конвейер:
o	SDL2 создает окно и рендерер → STL загружает и обрабатывает 3D-модели → SDL_image загружает текстуры → SDL2 рендерит результат
2.	Обработка моделей:
o	STL (fstream) читает OBJ-файл → Парсинг данных в векторы вершин → Преобразование в треугольники → SDL2 рендерит
3.	Освещение и материалы:
o	Математические расчеты (STL cmath) → Применение освещения к вершинам → SDL2 отрисовывает с учетом освещения
Использование в проекте
1.	Инициализация:
o	SDL2 и SDL_image инициализируются в начале программы
o	Создается окно и рендерер через SDL2
2.	Загрузка ресурсов:
o	OBJ-файлы загружаются через STL (fstream) и парсятся в структуры данных
o	Текстуры загружаются через SDL_image
3.	Основной цикл:
o	SDL2 обрабатывает события ввода
o	STL алгоритмы сортируют треугольники для правильного порядка отрисовки
o	Математические расчеты (поворот, проекция) выполняются с помощью cmath
o	SDL2 рендерит треугольники с учетом освещения и материалов
4.	Рендеринг:
o	Для каждого треугольника рассчитывается освещение
o	Треугольники отрисовываются либо как закрашенные полигоны, либо как вайрфрейм
o	SDL2 предоставляет функции для отрисовки линий и треугольников
5.	Очистка:
o	SDL2 освобождает ресурсы рендерера и окна
o	SDL_image освобождает текстуры
